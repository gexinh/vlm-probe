# Raw COCO report inputs

These unchanged photographs are the three fixed person/car/dog examples from
the technical report (COCO val2017 image IDs 14439, 263463 and 532575).
They contain no precomputed model or SAE results. Exact image hashes, source
URLs and noncrowd instance boxes are in
[sae_report_samples.json](../../sae_report_samples.json).

Images retain their original source rights. COCO annotation and image-source
information is available from [COCO](https://cocodataset.org/#termsofuse).
The library license does not relicense third-party photographs.
