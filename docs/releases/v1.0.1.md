# VLMProbe 1.0.1

vlmprobe provides Lens, Attention, Causal and SAE methods for language, vision
and multimodal models through a shared model-bound interface.

## Changes since 1.0.0

- Fix GitHub rendering of all 76 mathematical expressions in the SAE method
  guides while preserving their API signatures and complete examples.
- Organize the published checkpoint directory by 34 backbone models on one
  page, including per-layer CLIP and DINO tables with model cards and weights.
- Simplify the model hub to representative checkpoints and practical loading,
  search and training links.
- Complete 78 Gated, BatchTopK and Matryoshka BatchTopK model records from
  author configurations pinned to immutable source revisions. Preserve model
  identities, card paths and checkpoint-loading capabilities.

The release includes the native SAE methods, training workflows, visualization
and published model catalog introduced in
[1.0.0](https://github.com/gexinh/vlm-prob/releases/tag/v1.0.0).

## Installation

```bash
python -m pip install --upgrade "vlmprobe[sae,transformers,visualization]==1.0.1"
```

```python
import vlmprobe
from vlmprobe import Prober

print(vlmprobe.__version__)  # 1.0.1
```

The wheel and source distribution contain the installable library. Demos,
method guides, model cards and the technical report are maintained in the
repository and mirrored in the Hugging Face Space.
