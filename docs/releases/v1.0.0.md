# VLMProbe 1.0.0 — Exploring Model Internals Beyond the Answer

vlmprobe integrates Lens, Attention, Causal and SAE analyses into one interface
bound to a caller-owned language, vision or multimodal model.

## Changes since 0.9.0

- Add native sparse autoencoder methods and variants, including ReLU, TopK,
  Gated, JumpReLU, AbsTopK, BatchTopK, Matryoshka, archetypal dictionaries and
  pursuit encoders. Methods share model-bound fitting, loading and probing APIs.
- Provide training on independent user-supplied data splits, held-out
  validation, resumable checkpoints and portable inference artifacts.
- Add feature activity profiles, token/image feature maps, reconstruction
  controls and feature editing through the common result and visualization API.
- Integrate published language and vision SAE model information into our own
  searchable catalog, with direct author weight links and source conventions.
  Automatic loading currently includes the pinned GPT-2 layer-0 TopK recipe;
  other author formats require their documented conversion and matching binding.
- Rewrite method guides with explicit object creation, parameter descriptions,
  complete live examples, training/loading distinctions and actual plots.
- Add the four-family overview figure and update both project pages, with
  repository-specific navigation and searchable SAE model cards.

The native SAE implementation does not require installing SAELens, ViT-Prisma
or Overcomplete. Source attribution and third-party licenses are included.
Both `import vlmprobe` and the compatible `import vlm_probing` remain available.

## Installation

Install this GitHub release without cloning the repository:

```bash
python -m pip install "vlmprobe[sae,transformers,visualization] @ git+https://github.com/gexinh/vlm-prob.git@v1.0.0"
```

The release assets contain the wheel, source distribution and current technical
report. A GitHub release and a PyPI distribution are separate publications;
check the PyPI version before selecting an exact index version.

## Validation and scope

The complete CPU suite passes **452 tests**, with **2 optional author-checkpoint
tests skipped** and **179 subtests passed**. All 14 new SAE API snippets execute
against their complete model/input setup. Published-checkpoint loading and
native artifact reload were tested without training. Personal and lab project
pages pass browser checks, including their model catalog and existing archived
experiment controls.

The catalog preserves author metadata; inclusion does not claim automatic
loading support or new semantic evaluation for every checkpoint. Tiny synthetic
training examples demonstrate the API rather than feature interpretability on
a research dataset. Adapter capability checks and exact dictionary/backbone
matching remain required.
